## 3. 关键决策

### 3.1 解析器为什么搬进 core

`script_parser.py` 被 `ui/routine_uploader.py` import，是**领域逻辑**（剧本 ↔ 字符串），
和"工具"的定位不符。`tools/` 应该是"独立运行的辅助脚本"，不该是运行时依赖。

搬进 `core/` 后，`core` 的边界清晰了：**导演（director）+ 剧本（parser）**，
正好对应作者提的三层模型中间两层。

`generic_parser.py` 直接删除——它只有 1 个调用点，保留一层"为了兼容而兼容"的别名没有价值。

### 3.2 `AAA_general` 为什么改 `_general`

`AAA` 的唯一作用是让它在文件管理器里排到最前面。这是排序 hack，不是语义。
`_general` 同样排最前（下划线在字母前），但不会让人以为是"AAA 级素材"。

### 3.3 `assets/assets` 为什么改 `assets/characters`

`assets/assets` 完全无法回答"里面是什么"。`characters` 直接说明了内容：
角色素材。同时 `assets/ui` → `assets/input`，避免和代码里的 `ui/` 目录同名。

### 3.4 通用库 vs 每角色一套：数据给出了答案

作者纠结"AAA 覆盖不全 / 每角色一套浪费空间"。实测数据：

```
45 个角色目录，只有 8 个有素材，合计 102 张 png
空子目录 349 个（make_folders 批量铺出来的）
_general 只有 13 张（concerto_energy 10 / jump 1 / broadblade 1 / pistols 1）
```

**所以现在既不是 A 也不是 B，而是"B 的壳 + 半个 A"。**

正确做法其实是现有代码已经在做的**三级降级**，判据是"这张图会随角色变化吗"：

| 类型 | 放哪 | 理由 |
|---|---|---|
| 普攻 / 重击 | 专属，缺失按武器类型落通用 | 挥剑和挥拳不同，同武器相同 |
| 技能 / 解放 / 头像 / 回路 | **必须专属** | 就是角色自己的图 |
| 声骸 | **通用** | 取决于装备，与角色无关 |
| 跳跃 / 闪避 / 协奏值 | **通用** | 全员一致 |

按这张表，`_general` 里有 `concerto_energy` / `jump` / `normal_attack/<武器>` 是**正确设计**，
不是历史遗留。缺的是"为什么这样"的说明——现在写在 `assets/README.md` 里了。

### 3.5 README 的边界

**不是每个目录都要 README。** 判据：这个目录有没有"人要遵守的约定"。

| 要 README | 原因 |
|---|---|
| `assets/` | 命名规范、覆盖策略、加角色流程 |
| `configs/` | 剧本格式、字段表、黑话语法 |
| `tools/` | 每个工具干什么、放哪个子目录 |
| `tests/` | 怎么跑、改什么必须补测试 |
| `docs/` | changelog 与 gaps 的分工 |

| 不要 README | 原因 |
|---|---|
| `core/` `ui/` `utils/` | 说明写在 `__init__.py` docstring 里——IDE 能看、`help()` 能查、不会与代码脱节 |

## 5. 迁移说明（**破坏性**）

如果你在别处（快捷方式、外部脚本、IDE 运行配置）引用过这些路径，需要同步：

| 旧 | 新 |
|---|---|
| `core/preset/director.py` | `core/director.py` |
| `from core.preset.director import Director` | `from core.director import Director` |
| `tools/script_parser.py` | `core/script_parser.py` |
| `tools/generic_parser.py` (`GenericScriptParser`) | 删除，改用 `core.script_parser.ScriptParser` |
| `tools/routine_lint.py` | `tools/checks/routine_lint.py` |
| `tools/mem_probe.py` / `mem_bench.py` | `tools/checks/` |
| `tools/asset_factory_gui.py` | `tools/factory/asset_factory_gui.py` |
| `tools/wiki_spider.py` | `tools/factory/wiki_spider.py` |
| `tools/make_folders.py` | `tools/scaffold.py`（`--create` / `--prune`） |
| `assets/assets/` | `assets/characters/` |
| `assets/assets/AAA_general/` | `assets/characters/_general/` |
| `assets/ui/` | `assets/input/` |

`config.json` 与剧本 JSON **不需要改**——里面没有硬编码这些路径。

## 7. 遗留

- **349 个空子目录没删**。`scaffold.py --prune` 已就绪，但删除是作者的决定，
  没有自动执行。建议先 `--prune --dry-run` 看一遍。

- `assets/video` 2.6G 仍留在项目里（已 gitignore），建议移出或定期清理。
