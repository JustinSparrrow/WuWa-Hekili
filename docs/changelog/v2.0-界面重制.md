# v2.0 — 界面重制：苹果的克制 + 鸣潮的质感

> 一句话：**从"能用的 QSS 方格"换成"有设计系统的暗色玻璃"。**
> 悬浮窗变成一整块胶囊，头像 / 元素徽记 / 环形进度全部自绘；
> 管理窗口统一套了一层无边框玻璃外壳。

## 触发背景

作者的原话：

> 接下来需要你优化一下我们的前端窗口 UI 界面，其实我觉得你如果觉得 pyqt
> 没办法做出很好看的界面也可以换成其他编程语言编写，反正就是得好看，
> 然后尽可能来点鸣潮的图片之类的装饰一下。具体的风格我还没想好，
> 如果照抄的话我比较喜欢苹果那种界面风格？

三个诉求：

1. **好看**优先于其他一切
2. 要**鸣潮的装饰**
3. 风格参照**苹果**

"换语言"是允许的，所以先认真评估了这条路的代价。

## 为什么不换语言

| 方案 | 代价 | 结论 |
|---|---|---|
| Electron / Tauri 前端 | 输入监听、Director、素材解析全在 Python，得做进程通信；且 WebView 常驻内存 +80~120MB | ✗ |
| QtWebEngine（PySide6 内置浏览器） | 只换 UI 层，但同样 +100MB 级内存，和 v1.1「降内存」的目标直接冲突 | ✗ |
| Qt Quick / QML | 动画与效果更强，但要把 4 个窗口 + 自绘格子全部重写成 QML，透明置顶窗口的行为也得重调 | △ 风险大于收益 |
| **留在 QtWidgets，用 QPainter 自绘** | 没有任何额外依赖，内存不涨，现有信号/线程一处不动 | ✓ |

关键判断：**界面"土"不是因为 Qt 画不出来，而是因为一直用 QSS 堆样式。**
QSS 只能表达方块 + 圆角 + 描边 + 线性渐变，做不出连续曲率圆角、
柔和多层阴影、环形进度、噪点玻璃。这些 QPainter 全都能画，而且 Qt 的
反锯齿和渐变质量足以撑起"苹果味"。

## 设计取向

**苹果的克制** —— 大圆角、大量留白、无边框、柔和层次、动效短而软。
**鸣潮的质感** —— 墨黑玻璃底、香槟金细线、菱形分隔、六元素色点缀。

具体落成几条硬规则（都写在 `ui/theme.py` 顶部）：

```
颜色   近黑冷调底 (#1B2029 → #0A0D13)，只用一种强调色（香槟金 #E8C88C）
圆角   连续曲率（squircle，贝塞尔控制点系数 0.50），不用 QSS border-radius
层次   外阴影 16 层描边近似 + 顶部反光条 + 底部内侧压暗
字号   9.5 / 10 / 10.5 / 11 / 12.5 / 13.5 / 15 / 17
       中文最小 10px（实测 9px 会糊成一团笔画）
字距   小号标签加 0.8~1.6px 字距，这是"高级感"最便宜的做法
动效   OutExpo / OutCubic，200~300ms，超过 400ms 就显得拖
```

## 改法

### 1. 悬浮窗：四个漂浮方格 → 一整块玻璃胶囊

旧版是四个独立的小方框散在画面上，看起来像四张贴纸，没有"这是一条时间轴"的语义。
现在装进同一枚胶囊：

```
┌──────────────────────────────────────────────────────────────┐
│  ◯头像 │ [历史] [ 当前 ] [下一个][未来]     启动轴 24/49      │
│  元素徽记                                    切 · 琳奈        │
│                                              立即            │
└──────────────────────────────────────────────────────────────┘
```

- **头像常驻**：显示"现在是谁的轴"，切人时立刻跟上（素材取自角色 `avatar.png`）
- **元素徽记**：头像右下角一枚小圆牌，六元素各一个纯矢量符号
  （冷凝六角雪 / 热熔火苗 / 导电闪电 / 气动回旋 / 衍射星芒 / 湮灭倒锥），
  外圈还有一段元素色弧——**不依赖任何素材文件**
- **暖光**：当前格位置上烘了一层金色径向光。当前位置永远不变，所以这层光
  可以烘进缓存，一分钱不花，作用相当于舞台追光

### 2. 环形进度替代底部横条

旧版是格子底部一条 3px 金龙，从满缩到空。问题是它藏在图标下沿，
斜着看根本注意不到。

现在改成**沿格子描边走一圈的进度弧**：从 12 点钟方向顺时针填充，
白色高光 + 同色柔光只裹住这一段（满环时才是整圈金属渐变）。
读法变成"环满了就能按"，不需要理解"剩余的占位时间"这种概念。

实现要点：`QPainterPath` 没有"截取一段"的 API，用 `pointAtPercent`
按 72 个采样点近似；起点偏移量是 `半宽 - 圆角`（顶边中点），
**不是周长的一半**（那是右下角，第一版就错在这）。

### 3. 自绘透明度，丢掉 QGraphicsOpacityEffect

推进动画原本靠 `QGraphicsOpacityEffect` 的 opacity 属性插值。两个问题：

- 它会把每一格先渲染到离屏 pixmap 再合成，连招时 4~5 格 × 60fps 全在做这件事
- 离屏合成会让 `QWidget.render()`（截图工具用）算错子控件偏移 —— 截图里
  四个格子会飞到错的位置，排查了半天才发现是效果器的问题

改成 `ActionWidget` 自己维护 `_opacity`，paintEvent 里 `p.setOpacity()`。
QPropertyAnimation 照样能驱动（属性名仍是 `opacity`），但少了一层离屏缓冲。

### 4. 管理窗口统一外壳

新增 `ui/frame.py` 的 `GlassWindow`：无边框 + 半透明 + 圆角玻璃 +
自绘标题栏（左标题右关闭，整条可拖）+ 淡入。四个窗口全部继承它。

配套的 `theme.window_qss()` 只负责表单类控件（下拉框、输入框、列表、
滚动条、标签页）——这些有现成交互逻辑，换皮最划算，不值得自己重写。

### 5. 启动器：先回答"我上次打的是哪个轴"

顶部是一块"最近使用"区域：队伍三个角色的圆形头像 + 元素弧 + 轴名 + 两条轴的步数。
数据来源是 `configs/routines/` 里**修改时间最新**的那个 json，不用额外维护配置项。

下面三个入口做成极简文字行（无图标、无边框，hover 才亮），
外面套一张极淡的分组卡片 —— 不然三行字会浮在半空。

期间修掉的问题（都记一下，下次容易再犯）：

1. `drawText(QRectF, ...)` 会把字**裁在矩形内**，矩形高度随手给 14px
   会把中文的顶部削掉。必须用 `QFontMetricsF.height()`
2. `QGraphicsOpacityEffect` + `QWidget.render()` 会让子控件偏移（见上）
3. 环形进度起点算成"周长一半"，实际落在右下角
4. 面板透明度 0.90 时，紫色战斗特效会透上来把玻璃染成脏灰，
   提到 0.96 才干净

## 遗留 / 风险

| 问题 | 说明 | 建议 |
|---|---|---|
| 没有 UI 缩放 | 所有尺寸是固定像素，2K/4K 下观感偏小 | 加 `settings.ui_scale`，把几何常量乘一个系数 |
| 头像裁切不居中 | 部分角色立绘本身脸偏一侧，`zoom=1.16` 统一处理不了 | 需要按角色微调偏移表，或改用更大的官方立绘 |
| 系统对话框没换皮 | `QMessageBox` / `QInputDialog` 仍是 Windows 原生样式 | 出现频率低（只在报错/命名时），优先级不高 |
| 编辑器第二页仍丢字段 | `parallel` / `uncancellable` / `duration_ms` / `custom_icon` 保存时会被抹掉（v1.x 遗留） | 属功能缺陷，与本次 UI 无关，另行修复 |
| 换显示器不重算 DPR | 只在 showEvent 里清缓存；拖动跨屏时可能糊一下 | 监听 `screenChanged` 再清一次 |
| 预览图入仓 640KB | `docs/ui/backdrop.jpg` 是录像抽帧 | 只是设计迭代的参照物，可随时删 |
